# Results Directory

This directory stores outputs generated by running the outlier detection pipeline (`main.py`).

## Output Files

1. **Tabular Results**:
   - `detected_anomalies.csv`: All data records flagged as outliers with model consensus scores, individual model predictions, and anomaly severity indices.
   - `district_anomaly_summary.csv`: Aggregated statistics of anomalies by district (total anomalies, surge counts, drop counts, average impact).
   - `model_comparison_metrics.csv`: Inter-algorithm agreement indices (Jaccard similarity, correlation) and outlier detection rates.

2. **Visualizations**:
   - `timeseries_anomalies.png`: Multi-district tourist arrivals over time with highlighted outlier points (e.g. 2018 floods, 2020 lockdowns, festival surges).
   - `multivariate_outliers_scatter.png`: Domestic vs. foreign tourist volume with anomaly classifications.
   - `district_boxplots.png`: Distribution of arrivals across districts displaying statistical fences.
   - `model_agreement_heatmap.png`: Heatmap of correlation/overlap among Isolation Forest, LOF, One-Class SVM, IQR, and Z-score.
   - `seasonal_anomaly_matrix.png`: Month vs. District matrix highlighting anomalous seasons.
