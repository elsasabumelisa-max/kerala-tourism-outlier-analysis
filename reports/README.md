# Analytical Reports Directory

This directory contains narrative analysis reports and summaries synthesized from the data mining and outlier detection pipelines.

## Contents
- **`outlier_analysis_summary.md`**: Executive summary generated after pipeline execution, highlighting:
  - Critical temporal shocks (e.g. August 2018 floods, COVID-19 shock waves)
  - Super-peak anomalies (Onam, Christmas-New Year, Thrissur Pooram)
  - District vulnerability rankings (districts most sensitive to extreme variations)
  - Strategic policy and resource management recommendations for Kerala Tourism Department.
